# Taha Dahmane — Portfolio

Portfolio personnel bilingue (français / anglais), responsive, en HTML, CSS et JavaScript vanilla.

## Lancer en local
1. Décompresser le dossier.
2. Ouvrir `index.html` dans un navigateur.
3. Pour un serveur local, ouvrir le dossier dans VS Code puis utiliser Live Server.

## Personnalisation avant publication
- Vérifier les coordonnées et les liens dans `index.html`.
- Ajouter une photo professionnelle si souhaité.
- Ajouter les URL exactes des dépôts GitHub dans les cartes projets lorsque les dépôts sont prêts.
- Ajouter le CV PDF au dossier et un lien de téléchargement si souhaité.

## Publication gratuite avec GitHub Pages
1. Créer un dépôt GitHub public, par exemple `taha-portfolio`.
2. Envoyer les fichiers `index.html`, `style.css`, `script.js` et `README.md` à la racine du dépôt.
3. Dans le dépôt : **Settings → Pages**.
4. Choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
5. GitHub affichera l'adresse publique du site après le déploiement.

Les textes et projets présentés reprennent les informations du CV fourni. Les liens individuels des projets n'ont pas été inventés.
